# e-SMM public API kapsamı

12 Ekim 2026 tarihinde incelenen Dev ve Canlı public dokümanlarda e-SMM oluşturma, gönderme, listeleme veya belge indirme endpointi bulunmuyor.

`InvoiceProfile` içinde `ESMM` değerinin ve kaynak şemada SMM modellerinin bulunması, bu işlemlerin public API üzerinden kullanılabildiğini tek başına doğrulamaz. Bu nedenle repo doğrulanmamış bir e-SMM endpointi veya çalışan gönderim örneği sunmaz.

e-SMM entegrasyonu için destek@faturaport.com üzerinden public endpoint, istek/yanıt modeli ve test erişimi bilgilerini isteyin. Kapsam yayımlandığında bu rehbere .NET, PHP ve JSON örnekleri eklenebilir.
